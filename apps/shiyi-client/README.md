## 快速体验

- 双击 start-web.bat：使用 Edge 启动同一套 Flutter 代码的浏览器预览。第一次启动需要等待编译。
- 安卓手机：优先安装 deliverables/Shiyi-demo-arm64.apk（Android 7.0+、ARM64 手机）；debug 包为通用调试备选。
- 开发调试：手机开启开发者模式和 USB 调试，连接电脑后运行 start-android.bat。
- 重新打包：双击 build-apk.bat，执行静态检查、测试并打包调试版。
- 手机号体验：输入测试号码（例如 13800138000），勾选协议并获取验证码；使用页面显示的演示验证码登录，不会发送短信。
- 微信体验：勾选协议，点击“微信登录 · 演示”，再点击“确认体验登录”。
- 密码登录切换到“账号登录”。演示账号：demo；密码：Demo12345。可点击登录页“填入演示账号”，但必须手动勾选协议才能登录。
- 新注册账号是空联系人列表；demo 账号预置 3 位明确标记为“示例”的数字伙伴。

## Demo 边界

- 账号仅存在本机/当前浏览器，不是后端身份；本地密码使用随机盐和 PBKDF2-HMAC-SHA256（100,000 次）保存派生值，不保存明文密码。本地 SharedPreferences 不等同于生产级安全账户存储，请使用专用演示密码。
- 创建页素材先保存在本机；真实照片视频在明确授权并开始后上传肖像。没有训练形象或克隆声音。
- 独立文字聊天仍为本地演示。真实语音/照片视频连接配置的后端，授权后可使用麦克风；照片视频不打开摄像头。
- 设置中的连接测试仅访问 GET /api/v1/health；成功不意味着已经完成账号、人物同步或聊天接入。
- Android 调试安装包及演示 release 包使用调试签名，不能当成正式应用商店发布包。
- 为方便局域网调试，Android 开启 HTTP 明文访问；生产环境应启用 HTTPS 并关闭该选项。
- 图像限制 5 MB；会缩放至最大 600 像素宽保存。音频 Android 最大 20 MB，浏览器最大 2 MB。浏览器空间有限，适合少量演示素材。
- 创建页已支持真实麦克风录音；仅点击录音并授权后开始，离开创建页、切换标签或进入后台会取消当前录音并关闭麦克风，原已选样本保留。网页使用 HTTPS 或 localhost；通过局域网 HTTP 地址访问可能无法录音。声音在完成创建时保存，不会自动上传。
- 未实现声纹克隆、消息推送或跨设备同步。示例头像使用 Unsplash 摄影素材；姓名与人物设定为虚构。默认演示包不会连接微信或短信平台。

## 开发环境

项目 .toolchain 中已经配置 Flutter 3.47.7 / Dart 3.13.5、Zulu OpenJDK 17 x64、Android SDK 36、Build Tools 36、NDK、CMake、Gradle 缓存。脚本为当前进程设置环境变量，无需手动编辑系统 PATH。Flutter 工具已记录 SDK/JDK 路径。

scripts/env.ps1 使用 Flutter 中国镜像，并读取 Windows 已启用的单一 host:port 系统代理，供 Java/Gradle 下载依赖。迁移机器时，推荐安装官方 Flutter/Android Studio 并更新脚本，不复制大型 .toolchain。

由于项目在 E 盘、Pub 缓存在 C 盘，已关闭 Kotlin 增量编译并启用进程内编译，避免 Windows 跨盘缓存错误。保留 pubspec.lock 以复现依赖版本。

中文字体为 Noto Sans SC 的子集，许可证见 assets/fonts/OFL.txt；主要保留基本拉丁、常用中文及标点。
